# 🌸 Дачный и Домашний Планер Задач (PWA)

Удобный, быстрый и отзывчивый мобильный веб-планер, разработанный специально под интерфейс iPhone 8, но адаптирующийся под любые экраны. Позволяет организовывать дела по огороду, саду и дому, вести дневники и таблицы с автоматическими напоминаниями.

🌐 **Живой сайт проекта**: [https://planergarden.vercel.app](https://planergarden.vercel.app)

## ✨ Основные функции

* **📅 Умный Календарь**: вложенная навигация (Месяц -> Неделя -> День) с интерактивным выбором дат и удобной прокруткой.
* **✅ Списки Задач**: распределение задач по категориям («Огород» и «Дом»), установка точного времени для напоминаний.
* **📊 Интерактивные Таблицы**: создание кастомных таблиц из готовых шаблонов (например, дневник полива) с возможностью редактирования ячеек прямо на ходу и установкой индивидуального времени уведомлений.
* **⏰ Фоновые Web Push Уведомления (iOS/Android)**: напоминания приходят на заблокированный экран, даже если PWA полностью закрыто.
* **☁️ Облачная синхронизация**: мгновенная интеграция с Supabase (поддерживается гостевой анонимный вход без регистрации).
* **📱 Поддержка PWA**: приложение устанавливается на рабочий стол смартфона как нативное («На экран Домой»).
* **🌓 Темная тема**: автоматический выбор темы или переключение вручную.

## 🛠️ Технологический стек

* **Frontend**: Vue 3 (Composition API / `<script setup>`), Vite
* **Стилизация**: Ванильный адаптивный CSS (с подгонкой под безопасные зоны iOS)
* **Backend / База данных**: Supabase (PostgreSQL, Realtime, pg_cron, pg_net)
* **Хостинг / API**: Vercel (Node.js Serverless Functions)
* **Сервис-воркер**: PWA Service Worker (поддержка оффлайн-кэша и прием удаленных Web Push уведомлений)
